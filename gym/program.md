# Aktif Program — 5 Gün Üst / Alt / Push / Pull / Legs (Hipertrofi)

**Haftalık düzen:** Pzt Üst · Sal Alt · Çar dinlenme · Per Push · Cum Pull · Cmt Legs · Paz dinlenme
(Günler kayabilir; sıra korunur: A → B → C → D → E.)

**Kurallar**
- **Yoğunluk:** Her sette 1–3 tekrar yedekte bırak (RPE 7–9). İlk hafta 2–3 yedek.
- **İlerleme (çift ilerleme):** Tüm setlerde aralığın üst sınırına ulaşınca bir sonraki seans en küçük artış (makinede 1 kademe ≈ 2.5–5 kg).
- **Dinlenme:** Çok eklemli hareketler 2–3 dk, izolasyon 60–90 sn.
- **Ağırlıklar tahmini başlangıçtır.** Makine markasına göre değişir; ilk seansta tekrar aralığına göre ayarla ve `/gym-kaydet` ile kaydet.
- **Omuz ısınması (her üst/push/pull günü, 5 dk):** bant/kablo dış rotasyon 2x15 + face pull 1x15 hafif.
